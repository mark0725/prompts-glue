# Web 提示词工作台布局

## 概述

提示词工作台将「制作」「实时生成」「发布」合并为单一界面。用户在同一页面内用可视化拼图块或文本表达式构建提示词，执行生成并查看结果、依赖关系图与计算追踪；需要沉淀为包时开启「发布模式」填写 package 属性并发布，否则保持纯实时。本页取代原 `ui-web-composer.md`、`ui-web-generate.md`、`ui-web-publish.md`。表达式规则见 `prompts.md`，制作指令取值见 `dicts.md`「提示词制作指令」。

## 设计目标

- 一个界面覆盖「拼装 → 执行 → （可选）发布」全流程，减少页面跳转。
- 图形拼图与文本表达式双向同步，兼顾可视化与高效编辑。
- 实时与发布统一：默认实时无属性；按需开启发布模式展开属性。
- 依赖关系图、计算追踪、缓存与 token 信息在执行后统一展示。

## 整体线框

```
┌──────────────────────────────────────────────────────────────────┐

├──────────┬───────────────────────────────────────────────────────┤
│ 区块面板  │ 构建区（最大化，约 70vh）                              │
│ ▸ 输入    │ 图形视图：拼图画布（左→右数据流）                       │
│  引用 文本│ ┌──┐ → ┌──┐ → ┌──┐ → ┌──┐                            │
│ ▸ 指令    │ │引│   │清│   │摘│   │+│ …                            │
│  汇总 摘要│ └──┘   └──┘   └──┘   └──┘                            │

│  主题 模板│                                                       │
```

输出约束用「组合 `+` + 文本」实现，不单设输出块。

## 工具栏

| 元素 | 说明 |
|---|---|
| 图形 ⇄ 文本 | 切换构建区视图，双向同步表达式 |
| 发布模式开关 | 关=纯实时（无 package 属性）；开=展开属性区并启用发布 |
| 清空 | 清空画布/表达式与结果 |
| 生成提示词 | 以当前表达式调用生成接口 |

移动端工具栏折叠为图标，构建区与执行区上下排布。

## 区块面板

图形视图下显示，文本视图下隐藏。分类与表达式元素一一对应，取值见 `dicts.md`。

| 类别 | 区块 | 对应表达式元素 |
|---|---|---|
| 输入 | 提示词引用 | `包名` / `包名@版本规则` / `@scope/包名` |
| 输入 | 文本字面量 | `"文本"` |
| 指令 | 各制作指令 | `指令名(输入){"选项"}` |
| 组合 | 汇总 / 合并 / 标签 | `+` / `|` / `#` |

输出约束通过「组合 `+` + 文本字面量」实现（如 `expr + "约束"`），不单设输出块。指令块按 `dicts.md` 执行方式着色，区分本地确定性与 LLM 类，便于预估 token。

## 布局分区

| 区域 | 位置 | 内容 |
|---|---|---|
| 区块面板 | 左栏顶部（图形视图） | 输入/指令/组合区块 |
| 执行配置 | 左栏，区块面板下方 | 缓存策略、错误策略 |
| 构建区 | 中栏，占满剩余宽度 | 拼图画布或文本表达式编辑器，最小高度约为视口 70% |
| 结果区 | 构建区下方，全宽两列 | 生成结果、依赖关系图 |
| 发布模式 | 右侧抽屉（可开关） | package 属性与发布操作 |

左栏随滚动常驻；构建区最大化，区块面板与执行配置置左、结果置下。

## 类型区分（普通/组合）

工作台按表达式是否引用提示词包自动区分，并在工具栏与发布模式中展示类型徽标。

| 类型 | 判定 | 内容来源 |
|---|---|---|
| 普通提示词 | 表达式无提示词引用（纯文本或纯文本变换） | 人工文本 |
| 组合提示词 | 表达式包含提示词引用 | 表达式与依赖计算 |

发布时类型按此自动设定，无需手选；组合提示词保存表达式，普通提示词保存内容（可由执行结果回填）。

## 构建区（双视图）

| 视图 | 内容 |
|---|---|
| 图形视图 | 拼图画布：起始输入块 + 指令/组合块，左→右数据流，可重排、删除、配置参数 |
| 文本视图 | 等宽表达式编辑器，支持手写与粘贴 |
| 同步 | 切换视图时双向转换；文本解析失败时定位错误并高亮对应区块 |
| 表达式预览 | 构建区下方只读显示当前表达式 |

拼装规则：左→右数据流，单/双输入槽、指令参数槽、嵌套；咬合时即时校验类型匹配；引用链形成循环时禁止咬合并高亮循环路径；嵌套深度与区块数量受 `sdk.md` 运行预算限制，超限禁止继续拼装。

## 执行配置

| 项 | 取值 | 说明 |
|---|---|---|
| 缓存策略 | `cache_strategy` 字典 | 默认短期缓存 |
| 错误策略 | `error_strategy` 字典 | 严格 / 宽容 |

## 结果与追踪

| 元素 | 说明 |
|---|---|
| 生成内容 | Markdown 安全渲染，支持复制、下载 |
| 计算追踪 | 缓存命中、token 输入/输出/合计、耗时、模型 |
| 依赖 | 解析到的引用包及版本，可点击跳转详情 |
| 警告 | 非阻断性问题列表 |
| 依赖关系图 | 复合表达式执行后渲染：根→直接依赖→传递依赖，节点标注解析版本；循环高亮、缺失置灰 |

## 发布模式

关闭时隐藏属性区，行为等同实时生成。开启后展开属性区，将当前构建的表达式作为待发布内容。

### 属性区

| 字段 | 说明 |
|---|---|
| 包名 | 必填，符合包命名规则，支持作用域包 |
| 版本 | 必填，语义化版本；相同包名+版本不可覆盖 |
| 说明 | 必填 |
| 分类 | 必填，`prompt_category` 字典 |
| 类型 | 自动判定（见「类型区分」），不手选；组合保存表达式，普通保存内容 |
| 标签 | 可选 |
| 作者 / 仓库 / 主页 / 许可证 | 可选元信息 |
| 可见性 | `visibility` 字典 |
| 缓存策略 | `cache_strategy` 字典 |

### 发布操作

| 操作 | 行为 |
|---|---|
| 发布前校验 | dry-run：校验属性、表达式、依赖可解析，不落库；展示校验结果与依赖 |
| 发布 | 正式提交；成功后跳转该版本详情页 |
| 发布冲突 | 版本已存在返回冲突错误，不覆盖 |

### 类型与内容

| 类型 | 内容要求 |
|---|---|
| 普通提示词 | 内容必填，可由执行结果回填或手填 |
| 复合提示词 | 表达式必填（来自构建区），内容可由发布前计算回填 |

## 模式关系

| 状态 | 构建区 | 执行 | 属性区 | 发布 |
|---|---|---|---|---|
| 实时（发布模式关） | 可用 | 可用 | 隐藏 | 不可用 |
| 发布（发布模式开） | 可用 | 可用（用于预览与计算） | 展开 | 可用 |

实时模式下生成记录按匿名或当前用户记录；发布模式仅登录用户可用，未登录开启发布模式时引导登录。

## 状态与校验

| 状态 | 展示 |
|---|---|
| 空构建 | 引导添加首个区块/输入表达式 |
| 拼装校验 | 类型匹配、未连接块、引用包未发布、循环、超深度 |
| 生成中 | 结果区加载态，禁用重复提交 |
| 生成失败 | 错误码与可重试提示，附 `request_id`，定位出错区块 |
| 发布校验 | 字段错误 + 警告，阻断发布 |

## 响应式

| 断点 | 布局 |
|---|---|
| 宽屏/桌面 | 三栏：面板 / 构建 / 执行，发布区置底 |
| 平板 | 面板折叠抽屉，构建与执行上下排布 |
| 手机 | 标签切换三区，构建区横向滚动，发布区为底部抽屉 |

## 安全要求

- 不硬编码业务编码，分类/类型/可见性/缓存/错误策略/指令均来自字典 API。
- 文本块不得含密钥；引用块权限由后端判定。
- 访问令牌不写入 URL 或日志；错误不泄露敏感信息。
- 内容预览安全渲染，禁用浏览器原生弹窗。

## 验证要求

| 验证 | 内容 |
|---|---|
| 双视图同步 | 图形 ⇄ 文本互转一致 |
| 执行联调 | 构建→执行→结果→追踪→依赖图 |
| 发布联调 | 开启发布模式→填属性→dry-run→发布→详情 |
| 模式切换 | 实时/发布模式切换不丢失构建内容 |
| 响应式 | 三栏与移动端布局均可用 |
