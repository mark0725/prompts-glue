# 基础 API 设计

## 概述

基础 API 设计定义 prompts-glue 后端服务对 CLI、Web 和 Manager 提供接口时共同遵循的访问、认证、响应、分页、错误和安全约定。业务 API 文档只描述具体资源和业务字段，不重复定义通用规则。

## 访问约定

| 项目　　 | 说明　　　　　　　　　　|
| ----------| -------------------------|
| 数据格式 | 请求和响应使用 JSON　　 |
| 字符编码 | UTF-8　　　　　　　　　 |
| 时间格式 | UTC 时间　　　　　　　　|
| 认证方式 | Bearer Token　　　　　　|
| 响应结构 | 使用统一响应结构　　　　|
| 请求追踪 | 每个响应包含 request_id |
| 分页方式 | 页码分页　　　　　　　　|

## API 分组

| 分组 | 前缀 | 说明 |
|---|---|---|
| Registry API | `/api/registry` | 包注册、搜索、下载、发布、依赖和生成 |
| 字典 API | `/api/dicts` | 前端和客户端读取业务字典 |
| 管理 API | `/api/admin` | 管理端用户、字典、配置、风险、审计等运营能力 |
| 静态资源 | `/` | 可选托管 Web 和 Manager 构建产物 |

## 认证约定

需要认证的接口应在请求头携带访问凭据。

| Header | 说明 |
|---|---|
| Authorization | `Bearer <access_token>` |

访问令牌按 realm 绑定所属用户域：WEB 域令牌由 `/api/registry/auth/login` 签发，MANAGER 域令牌由 `/api/admin/auth/login` 签发。registry 路由接受任意已认证令牌（WEB 或 MANAGER），管理 API（`/api/admin/*`）仅接受 MANAGER 域令牌；WEB 域令牌访问管理 API 返回 403。匿名可访问的路由若携带令牌，令牌须有效。身份接口按域区分：web 用户用 `/api/registry/auth/me`、manager 用户用 `/api/admin/auth/me`。

认证凭据不得出现在 URL 查询参数、日志、业务内容、缓存内容或错误详情中。

## 统一响应

所有 API 响应使用统一结构。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| success | 布尔值 | 是 | 请求是否成功 |
| data | 任意 | 否 | 成功时的业务数据 |
| error | 错误对象 | 否 | 失败时的错误信息 |
| request_id | 字符串 | 是 | 请求追踪标识 |

成功响应应设置 `success` 为真。失败响应应设置 `success` 为假，并返回错误对象。

## 错误对象

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| code | 字符串 | 是 | 错误码，取值见 dicts.md |
| message | 字符串 | 是 | 面向用户的错误说明 |
| details | 映射 | 否 | 字段错误、依赖错误、权限错误等补充信息 |

错误信息应便于定位问题，但不得暴露密钥、令牌、密码、内部调用栈或其他敏感信息。

## 分页结构

列表接口统一使用分页结构。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| items | 列表 | 是 | 当前页数据 |
| page | 数值 | 是 | 当前页码 |
| page_size | 数值 | 是 | 每页数量 |
| total | 数值 | 是 | 总数量 |
| has_more | 布尔值 | 是 | 是否还有更多数据 |

分页接口应限制最大 `page_size`。

## 查询约定

| 参数 | 说明 |
|---|---|
| page | 当前页码，默认第一页 |
| page_size | 每页数量，受服务端最大值限制 |
| q | 关键词搜索 |
| sort | 排序字段 |
| order | 排序方向 |

业务接口可扩展自己的筛选条件。

## 字段命名

| 场景 | 约定 |
|---|---|
| JSON 字段 | 使用 snake_case |
| 时间字段 | 使用 `_at` 后缀 |
| 标识字段 | 使用 `_id` 后缀 |
| 布尔字段 | 使用 `is_`、`has_` 或明确语义 |

## 安全要求

- 写操作必须校验身份、权限和资源归属。
- 请求体大小、调用频率、分页大小、表达式长度和依赖深度应有上限。
- 对外错误信息不得泄露内部实现细节。
- 管理 API 必须要求认证和管理权限。
- 私有资源访问失败时，不应向无权限用户泄露资源是否存在。
- 所有重要写操作应记录审计日志。
