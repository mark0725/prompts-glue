# Web 登录布局

## 概述

登录页获取访问凭据并建立会话。登录成功后回跳到来源页面。访问令牌仅存于客户端受控存储，不写入 URL 或日志。页面在 `ui-web-layout.md` 框架内渲染，但采用居中卡片形态，不展示主导航的业务入口。

## 卡片内容

| 元素 | 说明 |
|---|---|
| 品牌图标与名称 | 与整体框架品牌区一致 |
| 副标题 | 「用户端门户」 |
| 用户名 | 必填，支持用户名或邮箱 |
| 密码 | 必填，密码型输入，可切换显示 |
| 错误提示 | 凭据错误时在按钮上方展示统一文案，不泄露具体失败原因 |
| 登录按钮 | 提交时展示「登录中…」进行中态，禁用重复提交 |

## 交互

| 行为 | 说明 |
|---|---|
| 回车提交 | 用户名、密码输入框聚焦时回车等同点击登录 |
| 登录成功 | 保存访问凭据，回跳来源页；无来源页时回到首页 |
| 登录失败 | 表单保留用户名，清空密码，展示错误 |
| 已登录访问登录页 | 直接回跳首页 |

## 安全

| 要求 | 说明 |
|---|---|
| 凭据传输 | 仅通过登录接口请求体提交，使用受控通道 |
| 凭据存储 | 访问令牌存于客户端受控存储，不写入 URL、日志、控制台 |
| 错误脱敏 | 登录错误不区分用户名是否存在，统一提示 |
| 会话失效 | 令牌过期或被吊销时清除本地会话并引导重新登录 |

## 来源页回跳

访问受保护页面（如发布、个人中心）时未登录，先记录来源路径再跳转登录；登录成功后回到该来源路径。
