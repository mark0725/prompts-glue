# Web 包详情与版本详情布局

## 概述

包详情展示跨版本概要，并在同一页内切换查看各版本的元数据、依赖、表达式、计算记录与内容预览。版本详情作为包详情页内的子区域呈现，不单独成页。页面在 `ui-web-layout.md` 框架内渲染。

## 页面线框

## 面包屑

`首页 / 分类 / 包名`，分类与包名可点击回跳。

## 包头区域

| 元素 | 来源 | 说明 |
|---|---|---|
| 包名 | 包概要 | 等宽字体、主标题 |
| 说明 | 包概要 | 完整展示 |
| 可见性 | `visibility` 字典 | 标签 |
| 分类 | `prompt_category` 字典 | 标签 |
| 状态 | `version_status` 字典 | 最新版本状态标签 |
| 标签 | 包标签 | 标签组 |
| 作者 / 仓库 / 主页 | 包概要 | 链接可点击 |
| 总下载量 | 包概要 | 统计数字 |
| 复制安装命令 | — | 复制 `glue add <name>` 到剪贴板，Toast 反馈 |
| 下载最新内容 | 内容接口 | 跳转到最新版本内容预览并触发下载 |

## 版本选择

| 形态 | 说明 |
|---|---|
| 版本下拉 | 默认展示最新可用版本，展开列出全部版本 |
| 版本项 | 版本号 + 状态标签 + 发布时间；已废弃版本标注废弃标记 |
| 选择行为 | 切换版本后刷新元信息、依赖、内容区，不整页跳转 |

`latest_version` 仅指向可用已发布版本；已废弃版本可被选择查看，但不作为默认最新。

## 版本详情区

选中版本后展示的子区域，采用左右栏：左栏元信息，右栏切换 Tab。

### 元信息栏

| 字段 | 来源 | 说明 |
|---|---|---|
| 类型 | `prompt_type` 字典 | 普通提示词 / 复合提示词 |
| 表达式 | 版本表达式 | 复合提示词展示，等宽、可复制 |
| 缓存策略 | `cache_strategy` 字典 | 该版本缓存策略 |
| token 用量 | 版本计算记录 | 输入 / 输出 / 合计 |
| 计算时间 | 版本计算记录 | 最近计算完成时间 |
| 发布者 / 发布时间 | 版本详情 | 审计信息 |

### 内容与依赖 Tab

| Tab | 内容 |
|---|---|
| 内容预览 | Markdown 安全渲染；支持复制、下载、折叠；下载返回校验摘要 |
| 依赖 | 直接依赖列表：包名 @ 解析版本，可点击跳转到依赖包详情；复合提示词必填 |
| 事件 | 版本生命周期事件时间线：创建、发布、计算、废弃等 |

## 复合提示词

复合版本额外强调表达式与依赖：

- 表达式以代码块展示，保留原始文本。
- 依赖列表展示解析版本与是否影响计算。
- 计算记录展示缓存命中、token 与耗时。

## 依赖关系图

复合提示词在版本详情区展示依赖关系图：分层有向图展示该版本→直接依赖→传递依赖，节点标注解析版本，可点击跳转依赖包详情。检测到循环时高亮路径，缺失依赖节点置灰。与 `ui-web-workbench.md` 的「依赖关系图」共用图数据结构与渲染约定。依赖列表 Tab 与图互为表/图视图。

## 废弃版本

选中已废弃版本时，页面顶部展示醒目废弃提示：

| 元素 | 说明 |
|---|---|
| 废弃原因 | 来自版本废弃记录 |
| 替代建议 | 推荐替代包或版本（若有），可点击跳转 |

废弃不删除历史内容，仍可查看与下载以保证可复现性。

## 私有包

私有或内部包需登录且具备权限；无权限时返回权限错误，不暴露资源是否存在。
