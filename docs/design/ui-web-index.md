# Web 首页与搜索布局

## 概述

首页与搜索结果共用同一页面。未输入关键词时展示推荐内容（最新发布、热门包）；输入关键词或选择筛选后切换为搜索结果视图。页面在 `ui-web-layout.md` 定义的整体框架内渲染。

## 顶部筛选区

| 元素 | 说明 |
|---|---|
| 分类标签 | 第一项「全部」，其余来自字典 `prompt_category`；单选，选中后作为筛选条件并刷新结果 |
| 搜索框 | 占位提示「搜索包名、说明或标签」；回车提交、输入防抖、支持清除 |
| 高级筛选 | 可展开面板，提供类型（`prompt_type`）、状态（`version_status`）、标签、作者筛选，均来自字典或接口字段 |
| 排序 | 最新、热门、下载量；默认最新 |

筛选条件变化时重置到第一页并刷新结果；筛选状态可被用户一键清除。

## 提示词卡片

网格采用最小宽度 + 自动填充，列数随视口自适应（断点见 `ui-web-layout.md`）。

```
┌─────────────────────────────┐
│ 包名                  [状态] │
│ 一句话说明（最多两行截断）… │
│ [分类] [标签] [标签]         │
│ 最新 1.2.0   作者 · ⬇ 1234  │
└─────────────────────────────┘
```

| 卡片字段 | 来源 | 说明 |
|---|---|---|
| 包名 | 包概要 | 等宽字体，点击进入详情 |
| 说明 | 包概要 | 两行截断 |
| 状态 | `version_status` 字典 | 标签 + 语义色，已废弃使用警告色 |
| 分类 | `prompt_category` 字典 | 标签 |
| 标签 | 包标签 | 最多展示 3 个 |
| 最新版本 | 包概要 | 无版本时显示「暂无版本」 |
| 作者 / 下载量 | 包概要 | 辅助信息 |

卡片 hover 轻微抬起；废弃包卡片降低视觉优先级但仍可点击。

## 视图差异

| 视图 | 触发条件 | 内容 |
|---|---|---|
| 推荐视图 | 无关键词且无筛选 | 顶部「最新发布」与「热门包」两个分组，各取若干卡片 |
| 搜索视图 | 有关键词或筛选 | 统一结果列表，按所选排序展示 |

## 状态

| 状态 | 展示 |
|---|---|
| 加载中 | 卡片骨架屏 |
| 空结果 | 空状态插画 + 文案 + 「清除筛选」按钮 |
| 加载失败 | 错误文案 + `request_id` + 重试按钮 |

## 分页

结果较多时使用分页栏（见通用组件）。也可在移动端改为「加载更多」，但需展示总数与是否还有更多。
