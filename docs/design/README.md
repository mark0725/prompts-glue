# 总体设计

## 系统概述

提示词构建器（Prompts Builder）是一个用于结构化设计、组合、存储和复用提示词的系统。它通过将提示词拆分为可独立管理的指令单元，并使用表达式完成内容计算、条件判断、重复渲染和参数传递，使提示词的制作过程可维护、可版本化、可协作。

## 核心目标

- 将提示词从纯文本提升为结构化、表达式驱动的对象
- 支持提示词的模块化复用和版本管理
- 提供与具体模型和编程语言无关的抽象设计
- 保证提示词渲染结果的可预测性和可追踪性

## 关键概念

- **提示词（Prompt）**：由一个或多个指令组成、可渲染为最终文本或消息序列的结构化对象。
- **指令（Instruction）**：提示词的最小组成单元，每种指令类型承担不同的语义职责。
- **表达式（Expression）**：在渲染时基于上下文计算内容、判断可见性、生成参数或提供重复数据的声明式规则。
- **上下文（Context）**：渲染提示词时传入的变量集合，是表达式求值的数据来源。
- **存储（Storage）**：提示词及其元数据、版本、引用关系的持久化机制。
