# Web 个人中心布局

## 概述

个人中心展示当前用户信息、已发布提示词包、命名空间与基础偏好。从顶部 Header 的用户下拉菜单进入。仅登录用户可用。页面在 `ui-web-layout.md` 框架内渲染。

## 页面线框

```
┌──────────────────────────────────────────────────────────────────┐
│  [头像]  admin                                                    │
│          显示名 · 角色[管理员] · 正常                              │
│          最近登录 2026-07-10 09:53          [退出登录]            │
├──────────────────────────────────────────────────────────────────┤
│  [我发布的]  [我的命名空间]  [生成历史]  [偏好设置]                │
├──────────────────────────────────────────────────────────────────┤
│  我发布的提示词                                                   │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │ 包名          分类   最新版本   状态    下载                 │  │
│  │ my-prompt     后端   1.2.0     已发布  1234   [查看]        │  │
│  └────────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────┘
```

## 用户卡

| 元素 | 来源 | 说明 |
|---|---|---|
| 头像 | 用户信息 | 无头像时用首字母占位 |
| 用户名 / 显示名 | 用户信息 | 主标识 |
| 角色 | `account_role` 字典 | 账号角色标签 |
| 状态 | `account_status` 字典 | 账号状态 |
| 最近登录 | 用户信息 | 辅助信息 |
| 退出登录 | — | 清除会话并回到首页 |

## 内容 Tab

| Tab | 内容 |
|---|---|
| 我发布的 | 当前用户拥有的提示词包列表：包名、分类、最新版本、状态、下载量，可跳转详情 |
| 我的收藏 | 当前用户收藏（star）的提示词包列表，字段同「我发布的」，可跳转详情 |
| 我的命名空间 | 用户所属命名空间：名称、角色（`namespace_role` 字典）、成员数、包数量 |
| 生成历史 | 当前用户的实时生成记录：表达式摘要、token、缓存命中、时间，顶部展示累计 token 消耗 |
| 访问令牌 | 当前用户的访问令牌（登录令牌与个人访问令牌）：名称、创建、最近使用、过期、吊销；可新建令牌（默认永不过期，可设过期），明文仅创建时返回一次并提示复制 |
| 偏好设置 | 界面偏好（主题、语言、列表密度等非业务设置） |

## 我发布的提示词

- 仅展示当前用户拥有的公开与私有包。
- 列表支持分页，字段编码经字典映射为标签。
- 行操作：查看详情；后续可扩展废弃、编辑草稿等维护操作（需对应权限与接口）。

## 我的命名空间

| 字段 | 说明 |
|---|---|
| 名称 | 命名空间名称，作用域包前缀 |
| 角色 | 用户在该命名空间的角色，`namespace_role` 字典 |
| 成员数 / 包数量 | 命名空间统计 |

命名空间成员与包维护的完整管理在 Manager 完成，个人中心以查看为主。

## 生成历史

来源为当前用户的生成记录，字段与实时生成结果区一致（表达式摘要、token、缓存命中、耗时、时间），用于回溯个人调用与成本。

## 权限

- 未登录访问个人中心时引导登录。
- 数据范围限定为当前用户自有资源；私有资源需权限校验，由后端判定。
