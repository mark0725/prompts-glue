# Web 整体框架布局

## 概述

定义用户端门户所有页面共享的界面框架：顶部导航、内容容器、底部页脚、响应式规则和通用组件。各业务页面在此框架内渲染，保持视觉与交互一致。页面级布局见 `ui-web-index.md`、`ui-web-detail.md`、`ui-web-workbench.md`、`ui-web-userspace.md`、`ui-web-auth.md`。

## 整体线框

```
┌──────────────────────────────────────────────────────────────────┐
│ [logo] Prompts Glue   浏览  实时生成  发布      [搜索…]  用户区▾  │  顶部 Header（固定）
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│                       内容区（最大宽度居中）                       │
│                                                                  │
├──────────────────────────────────────────────────────────────────┤
│  Prompts Glue · 提示词构建与分发      文档  CLI 安装  关于          │  底部 Footer
└──────────────────────────────────────────────────────────────────┘
```

## 顶部 Header

固定在视口顶部，含品牌区、主导航、搜索入口和用户区。

| 区域 | 内容 | 说明 |
|---|---|---|
| 品牌区 | 系统图标 + 文案 `Prompts Glue` | 点击回到首页 |
| 主导航 | 浏览、实时生成、发布 | 当前页高亮；发布对未登录用户显示但点击后引导登录 |
| 搜索入口 | 搜索框 | 默认折叠为图标，展开后输入即跳转搜索结果（见 `ui-web-index.md`） |
| 用户区 | 未登录显示「登录」按钮；已登录显示头像 + 下拉菜单 | 下拉项：个人中心、退出登录 |

移动端：品牌区保留，主导航收入抽屉或底部标签栏，搜索框折叠为图标。

## 内容容器

| 属性 | 说明 |
|---|---|
| 最大宽度 | 桌面约 1200px，超宽屏两侧留白 |
| 对齐 | 水平居中 |
| 内边距 | 桌面两侧 24px，移动端两侧 16px |
| 垂直间距 | 区块之间使用统一间距阶梯 |

详情、生成、发布等操作密集页面可在容器内使用更宽的双栏布局。

## 底部 Footer

| 内容 | 说明 |
|---|---|
| 品牌与一句话定位 | `Prompts Glue · 提示词构建与分发` |
| 辅助链接 | 使用文档、CLI 安装说明、关于 |
| 版权与许可证 | MIT |

Footer 不承载业务操作，保持简洁。

## 响应式规则

按视口宽度划分断点，卡片网格与导航形态随之适配。

| 断点 | 视口宽度 | 提示词卡片列数 | 导航形态 | 搜索框 |
|---|---|---|---|---|
| 宽屏 | ≥ 1280px | 4 列 | 顶部水平导航 | 常驻展开 |
| 桌面 | 992–1279px | 3 列 | 顶部水平导航 | 常驻展开 |
| 平板 | 768–991px | 2 列 | 顶部导航或抽屉 | 折叠为图标 |
| 手机 | < 768px | 1 列 | 底部标签栏或抽屉 | 折叠为图标 |

卡片网格采用最小宽度 + 自动填充策略：容器按 `auto-fill, minmax(最小宽度, 1fr)` 排列，列数随可用宽度自适应，而非写死断点列数。

## 主题与视觉

| 项 | 约定 |
|---|---|
| 主色 | 与品牌图标一致的主色调，用于主要按钮、激活态、链接 |
| 圆角 | 统一圆角阶梯 |
| 阴影 | 卡片、弹窗使用轻微阴影体现层级 |
| 状态色 | 成功、警告、危险、信息各有对应语义色 |

页面内展示的分类、类型、状态、可见性、缓存策略等编码一律通过字典 API 加载并映射为标签与语义色，不在前端硬编码。

## 通用组件

各页面复用的组件清单。

| 组件 | 说明 |
|---|---|
| 提示词卡片 | 包名、说明、分类与状态标签、最新版本、作者、下载量、引用量、收藏量与收藏按钮；点击进入详情 |
| 标签 Badge | 渲染字典编码为可读标签，附带语义色（状态、类型、可见性） |
| 字典选择器 | 分类、类型、状态、缓存策略等筛选与表单选项的数据源均为字典 |
| 分页栏 | 显示总数、当前页、每页条数、是否还有更多 |
| 搜索框 | 支持回车提交、清除、防抖 |
| 对话框 | 替代浏览器原生确认框，用于下载、另存、退出等确认 |
| Toast | 操作结果反馈，失败时附带 `request_id` |
| 加载骨架 | 列表与卡片加载时展示骨架屏 |
| 空状态 | 无数据时的说明与引导 |
| 面包屑 | 详情类页面展示层级路径 |

## 导航与权限

| 访问目标 | 未登录 | 已登录 |
|---|---|---|
| 浏览、搜索、详情、内容下载 | 允许 | 允许 |
| 实时生成 | 允许（匿名生成） | 允许，可另存为包 |
| 发布提示词 | 引导登录 | 允许 |
| 个人中心 | 引导登录 | 允许 |

访问令牌仅存于客户端受控存储，不写入 URL，不输出到日志或控制台。

## 交互约定

- 所有异步操作展示进行中状态，禁用重复提交。
- 失败提示可读并附带 `request_id`，便于定位。
- 高影响操作（下载覆盖、另存、退出）使用 React 对话框确认，禁用浏览器原生弹窗。
- 内容预览安全渲染，不执行用户提供的脚本或 HTML。
